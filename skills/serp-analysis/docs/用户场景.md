## 场景一 · SEO 内容矩阵助理的日常用法

- **角色**：SEO 内容矩阵助理
- **触发时机**：需要「SERP 分析摘要」这件事有结果的时候
- **他会说**：`用 serp-analysis 帮我SERP分析`
- **需要准备**：关键词；SERP 内容（链接或用户提供的摘要）
- **拿到什么**：SERP 摘要表 + 覆盖点/空白点 + 大纲建议
- **容易踩的坑**：小样本（Top5）得出的空白点未必是机会，可能是无需求

---

## 场景二 · 换成你自己的材料

同一句话，把材料换成你手头的真实数据即可：

```text
用 serp-analysis 处理下面这份材料：
<粘贴你的内容 / 贴文件路径>
```

**输入结构不要改**：字段名变了，脚本会读不到；缺字段时应当被明确告知缺什么，而不是猜。

| 字段 | 必填 | 说明 |
|---|---|---|
| 关键词 | ✅ | 缺失会导致输出不可用 |
| SERP 内容（链接或用户提供的摘要） | ✅ | 缺失会导致输出不可用 |
| 目标站点 | ⬜ | 有则更好 |
| 竞品站点 | ⬜ | 有则更好 |
